07 · How the algorithm works

Objective: Maximize C(x) = Σ wᵤᵥ · [xᵤ ≠ xᵥ]

1. Prepare an equal superposition of computational basis states.

2. Apply the cost unitary for each graph edge.

3. Apply the mixing unitary for each QAOA layer.

4. Search candidate parameters and estimate the expected cut.

5. Simulate measurements and compare the result with the exact classical optimum.
